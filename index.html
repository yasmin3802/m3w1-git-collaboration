THE PROCESS

My Git Workflow

Each step keeps my project organized and makes collaboration easier.

01
●

Start on Main

The main branch contains the stable version of the project.

02
⑂

Create a Branch

I create a separate branch before working on a new feature or change.

03
✓

Make & Commit

After making changes, I save them with a clear and meaningful commit message.

04
↑

Push Changes

I push my branch to GitHub so the changes are available remotely.

05
↗

Open a Pull Request

A Pull Request allows changes to be reviewed before they are merged into main.

06
↳

Merge

Once the changes are ready, the feature branch can be merged into the main branch.

QUICK REFERENCE

Essential Git Commands

A few commands I use throughout the development process.

git status Check the current state of the repository.
git branch View available branches.
git switch -c feature/name Create and switch to a new feature branch.
git add . Stage the project changes.
git commit -m "message" Save staged changes with a message.
git push Send local commits to GitHub.
